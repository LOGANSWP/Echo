## 当前检查结果

- 独立 caption/OCR 存储、实际资产版本读取、用户校正优先和有界输入回归通过。
- PhotoKit reader 使用本地资源流、32 MB 限额、60 秒超时和取消；所选照片的按需处理接入同一队列和恢复注册，摄入与前台不再调度描述。
- 报告全为未准备照片时延后；可用照片的输入、每调用校验和 SQLite publication 使用相同有效素材。注入式报告发布和真实模型月报均通过；未变化照片的同步不会清除已准备素材，拍摄日期保持原值。
- 详情页与创作页显示真实素材状态，提供显式重试；不再要求先手写照片描述。UI 适配器刷新失败状态不会自动重试的测试通过。
- 保留原始失败证据：旧解码器不兼容、测试回调隔离崩溃、模拟器预授权与 iOS 26 系统权限状态不一致。最后一项通过真实系统授权弹窗恢复，不修改生产授权流程。
