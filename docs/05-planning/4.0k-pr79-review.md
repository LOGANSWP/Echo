### R79-1 / P1 — Required CI does not provision the newly mandatory generation resources

- **Location:** `Echo/App/AppComposition.swift:141-145`; `EchoTests/Phase4/4.0k_BundledGenerationIntegrationTests.swift:19`; `Scripts/prepare_generation_resources.py:69-79`.
- **Trigger:** A fresh CI checkout runs the required full test lane. AppComposition now always creates the real provider from `OfflineGenerationSimulator.bundle` in Debug simulator builds, but the bundle and its pinned sources are intentionally excluded from Git. The existing CI preparation invokes only `Scripts/prepare_models.sh`; it neither materializes nor verifies the new generation bundle. The added local preparation scripts require existing pinned files and are not invoked by CI.
- **Evidence:** [CI run 34301760595](https://github.com/logan-suu/Echo/actions/runs/34301760595), `Build, Lint & Test`, failed. The run executed 1,410 tests / 170 suites and reported 11 issues: **six new `invalidArtifact` issues**, plus five recorded historical known issues. Both real ingestion/report cases and all four real poem cases failed before generation. The model-quality assertions were not reached in these six CI cases.
- **Impact:** The required lane fails on a clean checkout and cannot validate the real production generation graph. Local selected-test success does not establish a reproducible CI or packaged artifact.
- **Fix:** Provide a controlled build-time source of the exact approved pinned artifact, materialize and verify the appropriate bundle before Xcode builds, and include artifact/preparation identity in any relevant cache key. Keep model binaries out of Git and prohibit App runtime downloads. Do not skip the six tests, swap in a fixture, or weaken checksum/approval gates. Re-run the required lane and address any subsequently exposed failures.
- **Rules:** AGENTS.md §3.4, §9.3, §15.2; ADR-023 exact-artifact and no-fixture acceptance.

### R79-2 / P2 — Reject oversized manual inputs before rendering the entire prompt

- **Location:** `Echo/Core/Services/StructuredGeneration.swift:50-56`, with the unbounded source load at `CreativePipeline.swift:346-369`.
- **Trigger:** Select a long imported note or a photo with a large persisted description. Manual generation only checks the number of source IDs (24), loads full effective text and passes it into the prompt builder. JSON encoding, JSON-to-String conversion, source joining and final prompt interpolation happen before the tokenizer's 16,384-byte input check. The 512-scalar report-excerpt path does not protect manual creation.
- **Evidence:** A temporary standalone Swift probe compiled the actual production `GenerationRequest`, `GenerationReferenceMap` and `StructuredGeneration` files with minimal surrounding type stubs, without changing repository code or running a model. A synthetic 1,000,000-byte source produced a fully rendered 1,000,333-byte user prompt with no construction-time rejection. This demonstrates late input bounding; it does **not** claim a measured jetsam/crash or real-model failure.
- **Impact:** Large stored text is copied/encoded repeatedly before the request is rejected, producing avoidable memory pressure and potentially exhausting memory before the runtime limit can protect the App.
- **Fix:** Add an early bounded source-read/aggregate-byte guard before encoding, joining or escaping text; retain exact tokenizer checks for the complete rendered prompt and output reservation. If rejecting oversized manual input, use the existing context-limit error without silently truncating source facts. Cover one oversized source, multiple sources exceeding the aggregate limit and JSON escaping expansion; verify rejection before serialization/inference.
- **Rules:** AGENTS.md §4.1/§4.3; ADR-023 §2 bounded source/input/resident memory; US-SYN-004 input-budget principle as shared runtime contract.
- **Tracking:** `DEF-79-003`, open, current PR before merge. Production code remains unchanged in this review.
