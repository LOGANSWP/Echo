## Debug 模拟器修复

独立图诊断定位到 FP16 RMS 数值失真，包括首 token 最终归一化及全部 logits 归零。提升 113 处 RMS 运算至 FP32 后，模拟器固定前缀恢复到 8/8 top-1，抽样 logits 最大绝对误差 1.4976063。首层注意力正确、清零 MLState 和更换优化提示均未修复，原 FP16 非量化模型也有同类错误。

`OfflineGenerationSimulator.bundle` 使用独立真实 Qwen3 CPU 计算图，量化权重 SHA256 仍为 `24cb6248d93c55437655bdfe1c218528c7c593c0fdda9374322e03ae8ac7bfd8`。完整 manifest 为 `4.0k-simulator-artifact-manifest.json`，派生身份为 `5a605e013f9bd0e2cfed9d7c44b99bc396628f82088c4aadd61865b1005a7a7f`。冻结审批附件未改动，派生图不声明设备或 Release 获批。

- `Scripts/convert_generation_simulator.py --output <new.mlpackage>`：校验冻结源，严格匹配 113 个 RMS 子图，FP32 归一化再回到 FP16；禁止覆盖或重新定义源 hash。
- `xcrun coremlcompiler compile <new.mlpackage> <output-directory> --platform iOS --deployment-target 18.0`：仅开发机预编译，App 不转换。
- 本机已冻结派生包及编译结果于 `PinnedModels/offline-generation-evaluation/qwen3-0.6b/simulator-rms-fp32-v1/`；`python3 Scripts/prepare_generation_simulator_resources.py --verify-only` 校验源及 Bundle；省略此参数只补充缺失资源，拒绝覆盖不匹配字节。
